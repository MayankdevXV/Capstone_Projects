
# 🎓 Capstone Projects Portfolio

Welcome to my Capstone Projects repository! This repository contains my academic projects, research work, hardware implementations, software applications, engineering simulations, reports, and presentations.

## 📚 About This Repository

Projects are organized using the following structure:

**Course → Project Type → Project Name**

This makes it easy to manage projects from multiple courses and find their related files.

## 🗂️ Project Categories

| Category | Description |
|---|---|
| 🔧 Hardware | Electronic circuits, sensors, embedded systems, and physical prototypes |
| 💻 Software | Websites, applications, programming projects, and software tools |
| 🧪 Simulation | Engineering simulations, modelling, and analysis |
| 🔗 Hybrid | Projects combining hardware and software |
| 📖 Research | Literature reviews, experimental studies, and research-based projects |

## 📁 Standard Project Files

Each project can contain the following folders:

- **Reports/** — Project reports and documentation
- **Source-Code/** — Programs and source files
- **Presentations/** — PPT and presentation materials
- **Results/** — Graphs, screenshots, measurements, and simulation outputs
- **References/** — Research papers, articles, and reference materials

## 🛠️ Tools and Technologies

The tools and technologies will depend on each project. They may include programming languages, electronic components, CAD tools, simulation software, and data analysis tools.

## 📌 Repository Goals

- Organize projects from multiple academic courses.
- Maintain project reports, code, presentations, and results in one place.
- Track project development using Git and GitHub.
- Make project documentation easier to access and maintain.
- Add new courses and projects as needed.
